# 假人信息屏蔽

**AI 声明：本项目完全由 OpenAI Codex 开发。**

[English](README.en.md)

Minecraft Java 版 26.3 Fabric 客户端模组，自动隐藏疑似批量假人的加入、退出和死亡提示。独立运行，不依赖假人盾构机或 Carpet；仅影响安装者的客户端显示。

## 识别方式

在一次服务器连接期间，模组观察在线玩家和原版加入消息，将“相同前缀 + 末尾数字”的名字自动分组。例如 `TBM_1` 和 `TBM_2` 属于同一组，无须预先指定 `TBM_`。当同组观察到 10 个不同数字后，开始隐藏该组所有符合结构名字的加入、退出和死亡提示，包括此前未出现过的编号。名字必须符合 Minecraft 玩家名长度及字符限制；前缀不区分大小写，数字的前导零不算新编号。

开始识别之前已经显示的消息不会删除。断开连接后识别结果会清空，重新连接时会重新观察当前在线玩家和后续加入者。由于只看名字结构，一组使用相同前缀加数字的真人也可能被识别为假人。

仅过滤原版翻译组件格式的加入、退出和死亡提示，且死亡提示只检查死亡者，不检查击杀者。普通聊天、玩家列表和动作栏不受影响；服务端或其他模组用纯文本或自定义格式发出的提示可能无法识别。网络数据和服务器日志不会被修改，其他模组仍可读取玩家在线信息。

## 安装

将 `build/libs/bot-message-filter-1.0.0.jar` 放入 Minecraft 26.3 的 Fabric 实例的 `mods` 目录，同时安装 Fabric API。需要 Java 25 和 Fabric Loader 0.19.5 或更高版本。本模组只需安装在客户端。

## 构建和测试

设置 `MC_DIR` 为 Minecraft 游戏目录后运行 `./build.sh`，或运行 `./test.sh` 构建并执行过滤逻辑测试。脚本需要 JDK 25 和该实例的 Minecraft、Fabric Loader、Fabric API 文件。测试不替代实际游戏内验证。
